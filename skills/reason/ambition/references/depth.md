# Depth: Do It the Way the Field's Best Would

Same outcome, higher standard. Source: Felix Rieseberg, "How to be more ambitious" (2026-10-13), Depth.

| Slot | Ask | Fails when |
|---|---|---|
| Expert moves | the two or three moves that separate expert from competent work: state the decision it serves, check base rates, reproduce before fixing, write the counter-argument | it lists generic virtues ("be thorough") |
| `Raw:` | the dataset, not the chart; logs and code, not the bug report; the filing, not the article; where it lives | it names a summary or a dashboard |
| `Instruments:` | the tools the best practitioners use, and why each fits | vocabulary changes but method does not (a markdown table where an expert uses a database or a statistical model) |
| `Assumption:` | the belief the task rests on, phrased so the raw data could refute it: "churn is an onboarding problem; reproduce that from raw events" | it cannot be wrong |
| `Target:` (optional) | where the result is measurable, a stretch target an order beyond the ask (200 ms, not 5 s), treated as reachable; report how far it got | — |
| `Judge:` `Pass:` `Fail:` | an outside check, ideally one the model can run: test suite, benchmark, reproduction, held-out data, ground truth, domain reviewer | the model judges itself |

When the work is already deep in the raw data, ask for new knowledge: a signal or cause not yet known, shown to predict on data it has not seen.
