# Range: Bring in Fields the Task Does Not Name

Source: Felix Rieseberg (2026-10-13), Range.

- `Verbs:` restate the noun as what it does: a quarterly review is "getting busy people to believe a cause-and-effect story and decide under uncertainty in 30 minutes".
- `Crew:` from the verbs, pick two or more fields that would change the result (analyst, journalist, editor; red team: short seller, forensic accountant), separated by `;`, each with the method it contributes.
- Ask what each field does ("research the position the way a short seller does"), never to write like it; role-play changes tone, not outcome.
- One field per sub-agent fits the `fanout` playbook.
