# Prior art

Stop at the first rung that answers:

1. Local — code, docs, plans, memory. An existing pattern → reuse it.
2. `librarian` — the library or API is known; cite upstream code with file:line. `gh` unavailable → `read`.
3. `read` — the approach is open; compare candidate solutions from docs and maintained projects.

Borrow ideas, not code; check the license before copying anything.
