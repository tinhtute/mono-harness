# Playbook: feature

1. `brainstorm` — classify the lane and `lock` the Goal; a tiny request needs no plan and goes straight to `work bounded`.
2. `librarian` / `read` — prior art; skip for a tiny request. Stop at the first rung that answers: local code, docs, plans, memory → `librarian` when the library or API is known (`gh` unavailable → `read`) → `read` when the approach is open; a wide-open design re-routes to `research` or `prototype`. Borrow ideas, not code; check the license.
3. `to-plan` — high-risk lane only; normal plans already carry phase `main`.
4. `work full` — red → green per requirement; each `done` names its acceptance check.
5. `check full` — an independent judge on the final phase; an inconclusive or wrong-surface result is not a pass.
6. `git` — commit, push or PR only when the owner asks.
7. `handoff` — record Current State; close the plan after a clean final check.

Reply: the outcome, the acceptance results, and the furthest delivery state reached.
